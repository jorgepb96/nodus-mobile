# Computed values in native consultation

Status: source implemented; local compilation and acceptance **pending**.

Canonical and portable container queries now retain formula errors and conditional colours under their actual mapped property identities. Native adapters preserve those values instead of discarding them when the computed text is empty. The physical-table projection also retains actual materialized error and colour fields.

The native phone cards, table and row inspector present a calculation error explicitly. An absent result with a known error cannot become “no computed value” or a guessed portable calculation. Successful retained values preserve supported canonical text colours. Diagnostics remain selectable in the inspector, with wrapping for narrow screens.

Prepared checks cover physical-to-displayed property mapping, missing computed text with actual error, malformed metadata and a canonical-data fixture with a circular formula projected through the portable container query. They have not been executed for this change. Final iPhone/iPad acceptance must verify wrapping, colour contrast and state changes when calculations recover; these visuals are not yet approved.
