## Ubicación y búsqueda de la conexión

La entrada prevista es **Settings → Application → Mobile connection**
(**Ajustes → Aplicación → Conexión móvil**).

En Desktop 5.18.0 la sección existe pero falta en el menú agrupado. Se puede abrir
buscando «Mobile connection» o «Conexión móvil» en Ajustes.

El [PR Desktop #1355](https://github.com/jorgepb96/nodus/pull/1355), con cambios
hasta `a14edbf5481a6dd868ae2ca6f8259e9848bed4cd`, añade la pestaña al grupo
Application y permite encontrarla mediante «Nodus Link», «iOS», «iPad», «iPadOS»
y «Android». Estos términos adicionales requieren una compilación de Desktop
que incorpore el arreglo. Android es únicamente un alias de búsqueda, no una
plataforma implementada. La corrección del menú pertenece al repositorio Desktop;
este repositorio registra la dependencia y las instrucciones del companion.

La vinculación usa código, QR o enlace para el workspace completo. El ordenador
debe estar encendido y accesible por la misma LAN o una VPN compatible. Si vuelve
a estar disponible, el móvil intenta recuperar la conexión ya autorizada.

- El propietario realizará las pruebas en iPhone físico. No se certifican cámara QR,

  generación, proveedores autónomos y sincronización de edición siguen retenidos y
  deshabilitados. No se promete una copia offline completa del workspace.
